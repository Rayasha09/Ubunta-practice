# PR05 — CPU Scheduling Simulator

## Описание

Реализация симулятора алгоритмов планирования процессов для практической работы №5 по операционным системам.

Вариант B.

## Реализованные алгоритмы

- **FCFS** — First Come, First Served.
- **SJF** — Shortest Job First.
- **SRTF** — Shortest Remaining Time First.
- **Priority** — приоритетное планирование с вытеснением и aging.
- **Round Robin (RR)** — планирование с временным квантом.

## Метрики

Программа рассчитывает:

- Среднее время ожидания.
- Среднее время оборота.
- Среднее время отклика.
- Загрузку CPU.
- Количество переключений контекста.

Для каждого алгоритма выводится диаграмма Ганта.

## Файлы проекта

- `sched.py` — симулятор планирования процессов.
- `set1.txt` — первый набор тестовых данных.
- `set2.txt` — второй набор тестовых данных.
- `set3.txt` — третий набор тестовых данных.
- `rr_graph.py` — построение графиков для Round Robin.
- `rr_waiting.png` — график среднего времени ожидания.
- `rr_switches.png` — график количества переключений контекста.

## Запуск

Пример запуска FCFS:

```bash
python3 sched.py --algo fcfs set1.txt
```

Пример запуска SRTF:

```bash
python3 sched.py --algo srtf set1.txt
```

Пример запуска Priority с aging:

```bash
python3 sched.py --algo priority --aging 5 set3.txt
```

Пример запуска Round Robin с квантом 3:

```bash
python3 sched.py --algo rr --quantum 3 set2.txt
```

## Графики Round Robin

Для построения графиков среднего времени ожидания и переключений контекста при разных значениях кванта:

```bash
python3 rr_graph.py
```

Скрипт проверяет кванты от 1 до 10 и сохраняет графики в файлы `rr_waiting.png` и `rr_switches.png`.
