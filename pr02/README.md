# Практическая работа №2 — Bash и системные вызовы

## Вариант B

## 1. Скрипт report.sh

Скрипт принимает каталог и уровень сообщений ERROR или WARN.

Запуск:

```bash
./report.sh data ERROR
Результат
Модуль        Количество
------------------------
auth          3
net           2
Проверка без аргументов
./report.sh
Результат:
Использование: ./report.sh <каталог> <уровень>
Уровень: ERROR или WARN
Код возврата:
echo $?
Результат:
1
Это означает, что при отсутствии аргументов программа завершилась с кодом 1, как требуется в задании.
