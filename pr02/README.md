# Практическая работа №2. Bash и системные вызовы

## Цель работы

Освоить написание Bash-скриптов, обработку файлов журналов и изучить системные вызовы Linux с помощью `strace`.

## Используемый датасет

Для работы использован датасет **Logs Dataset** с платформы Kaggle, содержащий файл `Linux.log` с системными сообщениями Linux.

Файл находится в каталоге `data/`.

Источник: https://www.kaggle.com/code/adepvenugopal/logs-dataset/input

## Структура проекта

- `report.sh` — Bash-скрипт для обработки журналов.
- `hello.py` — Python-скрипт для чтения файла журнала.
- `data/01.log`, `data/02.log` — примеры журналов.
- `data/Linux.log` — файл из датасета Kaggle.
- `trace.txt`, `cat_trace.txt` — файлы для сохранения результатов трассировки системных вызовов.

## Запуск

```bash
chmod +x report.sh
./report.sh data ERROR
./report.sh data WARN
./report.sh data INFO
./report.sh data ERROR --top 3

python3 hello.py data/Linux.log

strace -c ls
strace -c cat data/Linux.log
strace -f -o trace.txt python3 hello.py data/Linux.log
strace -e trace=openat cat data/Linux.log
```

## Особенности обработки логов

Файлы `01.log` и `02.log` могут содержать поле `module=...`, которое используется для подсчёта сообщений по модулям.

В `Linux.log` используется другой формат системных сообщений. Поскольку в нём нет единого поля уровня `ERROR`, `WARN` или `INFO`, скрипт выполняет приблизительную классификацию по ключевым словам.

## Системные вызовы

- `openat` — открытие файла.
- `read` — чтение данных.
- `write` — запись данных или вывод в терминал.
- `close` — закрытие файлового дескриптора.
- `mmap` — отображение области файла или памяти в адресное пространство процесса.

## Контрольные вопросы

**Почему программа не обращается к диску напрямую?**

Доступ к устройствам контролирует ядро операционной системы. Программы используют системные вызовы, что позволяет управлять доступом и защищать ресурсы.

**Почему системный вызов дороже обычной функции?**

Системный вызов требует перехода из пользовательского режима в режим ядра и обратно, что создаёт дополнительные затраты.
