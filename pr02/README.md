# Практическая работа №2. Bash и системные вызовы

## Цель работы

Освоить написание Bash-скриптов, обработку файлов журналов и изучить системные вызовы Linux с помощью `strace`.

## Используемый датасет

Для дополнительной обработки использован файл `Linux.log` из датасета Logs Dataset на платформе Kaggle.

Источник: https://www.kaggle.com/code/adepvenugopal/logs-dataset/input

## Структура проекта

- `report.sh` — Bash-скрипт для обработки журналов.
- `hello.py` — Python-скрипт для проверки файла и получения его размера.
- `data/01.log`, `data/02.log` — примеры журналов.
- `data/Linux.log` — файл из датасета Kaggle.
- `trace.txt` — трассировка системных вызовов Python-скрипта.
- `cat_trace.txt` — статистика системных вызовов команды `cat`.

## Запуск

```bash
chmod +x report.sh

./report.sh data ERROR
./report.sh data WARN
./report.sh data INFO
./report.sh data ERROR --top 3
./report.sh --top 3 data WARN

python3 hello.py data/Linux.log

strace -c ls
strace -c cat data/Linux.log
strace -f -o trace.txt python3 hello.py data/01.log
strace -e trace=openat cat data/Linux.log
```

## Что делает `report.sh`

Скрипт принимает каталог с файлами `.log` и уровень журнала (`ERROR`, `WARN` или `INFO`). Он подсчитывает сообщения по модулям и выводит таблицу с количеством совпадений. Опция `--top N` ограничивает вывод указанным количеством строк.

Для файлов с полем `module=...` используется уровень журнала. Для `Linux.log` применяется приблизительная классификация по ключевым словам, поскольку формат файла отличается.

## Системные вызовы и `strace`

`strace` позволяет наблюдать системные вызовы, выполняемые процессом.

- `openat` — открытие файлов и библиотек.
- `read` — чтение данных.
- `write` — запись данных или вывод в терминал.
- `close` — закрытие файлового дескриптора.
- `mmap` — отображение области памяти или файла в адресное пространство процесса.

Команда `strace -c` выводит статистику вызовов, а `strace -f -o trace.txt` сохраняет трассировку в файл.

## Ответы на контрольные вопросы

**Почему программа не обращается к диску напрямую?**

Доступ к устройствам контролирует ядро операционной системы. Программы используют системные вызовы, что помогает защищать ресурсы и данные других процессов.

**Почему системный вызов дороже обычной функции?**

Системный вызов требует перехода из пользовательского режима в режим ядра и обратно, что создаёт дополнительные затраты.
