# Практическая работа №1. Диагностическое тестирование и терминал Linux

## Цель работы

Познакомиться с терминалом Linux, изучить основные команды для получения информации о системе и научиться работать с каталогами, файлами и правами доступа.

## 1. Проверка системы

| Команда | Назначение |
|---|---|
| `whoami` | Определяет текущего пользователя |
| `pwd` | Выводит путь к текущему каталогу |
| `uname -a` | Показывает сведения о ядре и архитектуре системы |
| `lsb_release -a` | Выводит информацию о дистрибутиве Linux |

## 2. Работа с каталогами и файлами

```bash
mkdir -p ~/os-course/pr01
cd ~/os-course/pr01
```

Создание текстового файла:

```bash
echo "Практическая работа №1" > about.txt
echo "Знакомство с терминалом Linux" >> about.txt
```

Просмотр содержимого и списка файлов:

```bash
cat about.txt
ls -la
```

## 3. Права доступа и структура файлов

Команда `ls -la` отображает скрытые файлы, права доступа, владельца, группу, размер и дату изменения.

В обозначении прав доступа:
- `r` — чтение;
- `w` — запись;
- `x` — выполнение.

## 4. Пример результата

После выполнения команд:

- `whoami` показывает имя текущего пользователя.
- `pwd` показывает путь к текущему каталогу.
- `uname -a` показывает сведения о ядре Linux и архитектуре системы.
- `lsb_release -a` показывает информацию о дистрибутиве Linux.
- `cat about.txt` выводит содержимое созданного файла.

## 5. Объяснение `ls -la`

Команда `ls -la` отображает список файлов, включая скрытые, и информацию о них:

- первый столбец — тип файла и права доступа;
- второй — количество жёстких ссылок;
- третий — владелец;
- четвёртый — группа;
- пятый — размер файла в байтах;
- далее — дата и время изменения;
- последний столбец — имя файла.

В обозначении прав доступа:

- `r` — чтение;
- `w` — запись;
- `x` — выполнение.

## 6. Вывод

В ходе практической работы рассмотрены базовые команды Linux, навигация по каталогам, создание текстового файла и просмотр прав доступа.
